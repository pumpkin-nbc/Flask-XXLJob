# Basic example

A single-file example using direct initialization (`FlaskXXLJob(app)`).

## Run

```bash
.venv\Scripts\python.exe examples\basic\app.py
```

The access token is read from the `XXL_JOB_ACCESS_TOKEN` environment variable;
no real token or internal address is committed.
